# Auth
Frontend uses Firebase client SDK; backend never accepts passwords except register (Admin SDK createUser) and never verifies passwords (Admin SDK cannot). Login = verify ID token (firebaseUid from verified token only), upsert Mongo user, create Session (sha256-hashed refresh token), set HttpOnly SameSite=strict cookies accessToken (15m) + refreshToken (30d, rotated). OTP: 6-digit crypto.randomInt, sha256 stored, 10m expiry, 60s cooldown, 5 attempts, TTL index. Forgot-password sends Firebase reset link, generic response. Roles: user/support/admin/superadmin; statuses incl. pending default.
